# Superseded: public-topic subscriptions and replay revisions

Date: 2026-11-26
Status: superseded by the [agreed group-chat brief](2026-11-26-group-chats-design.md). No part of this proposal was implemented.

The user chose invite-only group chats with membership as the subscription, earlier history preferred for current members, and one supported protocol. Additional public chats are optional. The former future-only topic filters, independent subscription selector, immutable selection-revision intervals, parallel v1/v2 support and maintenance activation plan are not current requirements.

Do not execute the old continuation or use the old proposal as an implementation specification. The complete earlier design is available in Git at 714f8af; it is historical engineering work, not current user agreement.

Read the group-chat brief, the main spec and current handoff for preserved safety constraints and the next action.
